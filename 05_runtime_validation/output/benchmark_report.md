# 步骤 5 初始性能结果

- 平台：`Darwin arm64`（Apple M5，SME/SME2）
- 预取 Profile：`apple-m5`
- 重复次数/样本数：`8 / 7`，报告样本中位数
- 可比性：基线/预取来自同一 LLVM 18 IR 与 `-O1` 管线，仅 pass 开关不同
- 正确性：基线与预取 checksum 一致
- 2D 规模：`16384x1024`，基线 `1.674044` GUP/s，预取 `1.633527` GUP/s，加速比 `0.9758x`
- 3D 规模：`512x32x1024`，基线 `1.190614` GUP/s，预取 `1.235621` GUP/s，加速比 `1.0378x`

该结果用于建立基线，不足以单独确定最终 Profile。后续需增加冷热规模、距离/层级/策略消融和 PMU 计数。
