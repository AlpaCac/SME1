# Apple M5 原始缓存事件对比

- 算子：`3d`
- 编译 Profile：`apple-m5`
- Instruments 模板：`SME Stencil Cache Counters`
- 外层轮数：`3`，奇偶轮交换基线/预取采集顺序
- 采样：`counters-profile`，1 ms；下表为目标进程每轮累加值的中位数
- 有效目标进程样本数中位数：基线 `1518`，预取 `1676`

| 事件 | 基线中位数 | 预取中位数 | 中位数比值 | 逐轮比值范围 |
|---|---:|---:|---:|---:|
| `ARM_L1D_CACHE_RD` | 212843010 | 192985861 | 0.9067 | 0.3985-1.8852 |
| `ARM_L1D_CACHE_LMISS_RD` | 2425029 | 2170116 | 0.8949 | 0.4204-1.7808 |
| `PL2_CACHE_ACCESS` | 14692767 | 180004398 | 12.2512 | 8.5915-16.2650 |
| `PL2_CACHE_MISS_LD` | 1794672 | 91262319 | 50.8518 | 30.0931-55.6488 |

当前结果中，PL2 请求增长方向在各轮一致；L1D 事件波动更大，不能仅凭三轮中位数断言 miss 已稳定下降。这些值是 Instruments 对目标线程的归因采样增量，受 1 ms 采样、线程迁核和 PMU 复用影响，适合做同模板相对归因，不应解释为精确的全程序事件总数。必须结合配对墙钟结果判断预取是否有效。
