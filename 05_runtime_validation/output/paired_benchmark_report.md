# 步骤 5 同进程配对性能结果

- 平台：`Darwin arm64`（Apple M5，SME/SME2）
- 方法：同一进程链接基线/预取函数，奇偶样本交换执行顺序
- 重复次数/样本数/外层轮数：`8 / 9 / 3`
- 2D 配对加速比：中位数 `1.006802x`，轮间范围 `0.991017-1.009024x`
- 3D 配对加速比：中位数 `1.009638x`，轮间范围 `1.003892-1.030648x`
- 正确性：两组 checksum 均一致

配对加速比是每对样本 `baseline_time / prefetch_time` 的中位数，比独立进程中位数更能抑制启动、温度和调度漂移。
