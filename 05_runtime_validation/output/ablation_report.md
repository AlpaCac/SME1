# 步骤 5 预取类别消融

- 平台：`Darwin arm64`（Apple M5，SME/SME2）
- 可比性：同一 LLVM 18 IR、`-O1` 管线、问题规模和样本数
- 2D 规模：`16384x1024`
- 3D 规模：`512x32x1024`

- 正确性：所有变体 checksum 与无预取基线一致

## 2D5P

| 配置 | GUP/s | 相对基线 |
|---|---:|---:|
| 无预取 | 3.204911 | 1.0000x |
| row L1 KEEP（默认） | 3.151743 | 0.9834x |
| 关闭 row | 3.308146 | 1.0322x |

## 3D7P

| 配置 | GUP/s | 相对基线 |
|---|---:|---:|
| 无预取 | 2.336769 | 1.0000x |
| 全部默认类别 | 2.350345 | 1.0058x |
| `no_row` | 2.354066 | 1.0074x |
| `no_plane_l1` | 2.142318 | 0.9168x |
| `no_plane_l2` | 2.356102 | 1.0083x |
| `row_only` | 2.132818 | 0.9127x |
| `plane_l1_only` | 2.342821 | 1.0026x |
| `plane_l2_only` | 2.340272 | 1.0015x |

`no_row` 的 2D 代码不插入预取，其相对基线偏差可用于估计跨进程测量噪声。消融结果仍需跨规模复测并结合 PMU，不能直接固化为最终 Profile。
